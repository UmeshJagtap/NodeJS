!!!!! Docker Volumes !!!!!
Docker volumes store data permanently outside containers
so data remains safe even if containers are deleted or restarted.

Type | Syntax | Data Kaha Save Hota Hai | Use Case | Example Command

Bind Mount    -v "local-folder:container-folder     Local Machine	      Development	
docker run -it -v "D:\project:/app" ubuntu

Named Volume  -v volume-name:container-folder 	    Docker Internal Storage   Database Storage
docker run -it -v mongo-data:/data/db mongo

Example
CMD : docker exec -it tender_cohen bash
root@c87ba6:/app# curl http://strange_solomon:8000
{"message":"hello from docker 27"}
:/app# ls 
db.js      models         package-lock.json   socket.js
index.js   node_modules   package.json

If we stop and remove the container .. all data is lost ..
So to handle the container data, we have Docker Volumes
