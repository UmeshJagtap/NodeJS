Load Balancer :-
Load Balancer distributes incoming traffic across multiple backend servers.

Example :
 Request 1 -> Server1
 Request 2 -> Server2
 Request 3 -> Server3

Why Needed?
One server overload na ho.

Real Load Balancers
Technology          Types
---------------------------------
Nginx               software
AWS ELB             cloud service


Nginx :-
Nginx is a reverse proxy and load balancer used to manage traffic
between users and backend servers.

Flow :
Users ---> Nginx ---> Backend1 / Backend2

NGINX FEATURES
> reverse proxy
> load balancing
> SSL
> routing

(nginx) Load balancing for multiple servers.

[] advanced-backend-course/system-design/docker-compose.yml
> docker-compose.yml
  server1:
    build: ./server
    env_file:
      - ./server/.env
    environment:
      - SERVER_NAME="pehla server"
    ports:
      - 5001:7000

  # as containers are isolate, server can run on same ports
  server2:
    build: ./server
    env_file:
      - ./server/.env
    environment:
      - SERVER_NAME="doosra server"
    ports:
      - 5002:7000

  server3:
    build: ./server
    env_file:
      - ./server/.env
    environment:
      - SERVER_NAME="teesra server"
    ports:
      - 5003:7000

[] advanced-backend-course/system-design/nginx/nginx.conf
> nginx.conf
http {
    upstream backend {
        server server1:7000;
        server server2:7000;
        server server3:7000;
    }

    server {
        listen 80;
        location / {
            proxy_pass http://backend;
            # return 200 "hello from nginx --umesh_aj";
            # proxy_pass http://server:7000;
        }       
    }
}
