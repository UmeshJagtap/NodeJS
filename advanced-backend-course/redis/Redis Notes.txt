Steps
1. Client sends request to Server
2. Server checks Redis for data
3a. If Cache Hit --> retyrn data to client
3b. If Cache Miss--> fetch data from DB
4. DB returns data to Server
5. Server stores data in Redis (cache)
6. Server sends response to Client

Redis Defination
Redis is an in-memory key-value database used for super fast data access.
