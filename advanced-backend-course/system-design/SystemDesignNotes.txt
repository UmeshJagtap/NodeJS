Load Balancer :-
Load Balancer distributes incoming traffic across multiple backend servers.

Example :
 Request 1 -> Server1
 Request 2 -> Server2
 Request 3 -> Server3

Why Needed?
One server overload na ho.

Real Load Balancers
Technology          Types
---------------------------------
Nginx               software
AWS ELB             cloud service


Nginx :-
Nginx is a reverse proxy and load balancer used to manage traffic
between users and backend servers.

Flow :
Users ---> Nginx ---> Backend1 / Backend2

NGINX FEATURES
> reverse proxy
> load balancing
> SSL
> routing
